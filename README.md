# Sistema de Gestión de Biblioteca (MongoDB + Python)

## Integrantes
- Iván Morales

## Requisitos Previos
- Python 3.x instalado.
- Motor de base de datos MongoDB instalado y ejecutándose localmente en el puerto `27017`.
- Librería PyMongo instalada. `pip install pymongo`

## Instrucciones de Ejecución
1. Clonar este repositorio en el equipo local.
2. Abrir una terminal y buscar la carpeta del proyecto.
3. Ejecutar el archivo de configuración para crear la base de datos y cargar los documentos:
   `python setup.py`
4. Una vez poblada la base de datos, iniciar el sistema ejecutando el menú principal:
   `python main.py`
